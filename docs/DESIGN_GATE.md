# Design Gate

Обязателен перед созданием нового экрана, карточки или заметным визуальным изменением.

1. До кода изучить текущий интерфейс, токены и компоненты проекта.
2. Описать один визуальный вариант простым языком: иерархия, блоки, отступы, состояния и мобильная версия.
3. Сделать отдельный статичный HTML-прототип или макет в Figma, если она подключена, и приложить рендер целевого размера.
4. Не менять основной интерфейс до подтверждения направления пользователем.
5. После реализации сделать visual QA по рендеру: проверить переполнения, обрезание, пустые зоны, контраст, длинные русские строки и мобильный размер.
6. Завершать визуальную задачу только со скриншотом и коротким отчётом visual QA.

Для типовых компонентов сначала проверять совместимость существующего React-стека с shadcn/ui или другой подходящей библиотекой. Не устанавливать библиотеку и не менять стиль всего продукта без отдельного подтверждения.
