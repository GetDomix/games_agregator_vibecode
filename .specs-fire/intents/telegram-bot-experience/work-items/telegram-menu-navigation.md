# Work Item: Главное меню и навигация бота без команд

## Description

Сделать обычный путь в боте доступным через главное меню, reply-кнопки и inline-клавиатуры, чтобы поиск, избранное, алерты и возврат назад не требовали запоминать команды.

## Acceptance Criteria

- [ ] После `/start` пользователь видит понятное главное меню с поиском, избранным, алертами и справкой.
- [ ] Поиск, открытие карточки, настройка и возврат назад доступны кнопками без ввода slash-команд.
- [ ] Inline-клавиатуры показывают только действия, применимые к текущему экрану.
- [ ] Состояние незавершённого поиска или настройки не теряется при обычной навигации.
- [ ] Главные сценарии меню покрыты изолированными handler-тестами.

## Technical Notes

Команды могут остаться техническими запасными входами, но не должны быть нужны для основного сценария.
