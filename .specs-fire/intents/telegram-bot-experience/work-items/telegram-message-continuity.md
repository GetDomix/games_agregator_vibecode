# Work Item: Непрерывный диалог без дублирования сообщений

## Description

Сделать навигацию аккуратной: бот изменяет уже показанные экраны и карточки, когда это безопасно поддерживается Telegram, вместо накопления одинаковых сообщений в чате.

## Acceptance Criteria

- [ ] Повторное открытие раздела или обновление карточки не создаёт визуальный дубликат, если сообщение можно отредактировать.
- [ ] Для фото, caption и клавиатур выбрана корректная стратегия Telegram edit API с безопасным fallback.
- [ ] Пользователь видит понятный результат при устаревшем callback или невозможности отредактировать старое сообщение.
- [ ] Не удаляются пользовательские сообщения и не создаются повторные уведомления об успешном действии.
- [ ] Поведение edit/fallback покрыто handler-тестами.

## Technical Notes

Ограничения Telegram API определяют допустимый fallback; техническая реализация не должна изменять данные избранного или алертов.
