# Work Item: Бесплатный поиск и удаление Pro

## Description

Удалить подписки, платежные заготовки, промокоды и дневные квоты, сохранив бесплатный поиск, техническую защиту и ненавязчивую нейтральную рекламу.

## Acceptance Criteria

- [ ] Pro, тарифы, платежные запросы и промокоды удалены из сайта и API.
- [ ] Логика планов пользователя и дневные поисковые квоты больше не влияют на доступ к поиску.
- [ ] Устаревшие таблицы и поля удаляются новой проверенной миграцией без изменения старых миграций.
- [ ] Гости и пользователи ищут бесплатно с техническим rate limit.
- [ ] Реклама не показывается popup или полноэкранным перекрытием и не разрывает основной блок результатов.
- [ ] Партнёрский идентификатор и рекламная конфигурация не меняют состав, порядок или выделение предложений.
- [ ] Существующий пользователь без Pro продолжает авторизоваться и использовать избранное после миграции.

## Technical Notes

Удаление данных требует отдельного Validate-checkpoint и плана отката. Рекламный блок допустим после результатов и внизу страницы; новые партнёрские механики не добавляются.
