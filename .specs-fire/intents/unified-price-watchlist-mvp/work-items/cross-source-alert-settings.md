# Work Item: Избранное и настройка алертов

## Description

Расширить избранное настройками площадок и видов предложений, одной целевой ценой и явным жизненным циклом алерта.

## Acceptance Criteria

- [ ] Пользователь выбирает Steam, Plati и/или GGsel и допустимые виды предложения для маркетплейсов.
- [ ] `account` и `rent` выключены по умолчанию; неопределённый `other` не включается в алерт автоматически.
- [ ] Одна целевая цена применяется только к выбранным комбинациям площадки и вида.
- [ ] Алерт имеет состояния `active` и `triggered` и может быть явно переактивирован.
- [ ] Изменение целевой цены возвращает алерт в `active`.
- [ ] API отклоняет пустой набор источников, неизвестные виды и некорректную цену.
- [ ] Поле типа условия поддерживает `target_price` сейчас и допускает `discount_percent` позднее без замены избранного.
- [ ] `last_steam_price_rub` и другие наблюдаемые цены больше не принимаются от клиента.

## Technical Notes

Настройки принадлежат пользовательскому favorite/alert, а текущие цены принадлежат канонической игре. Модель должна позволить объединять настройки при связывании аккаунтов.
