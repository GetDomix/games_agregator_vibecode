# Work Item: Единая модель игр и цен

## Description

Создать каноническую серверную модель игры, текущих предложений и истории цен, общую для всех пользователей, и подготовить безопасный перенос пригодных данных из существующих таблиц.

## Acceptance Criteria

- [ ] Игра однозначно идентифицируется Steam `appid` и хранит название, изображение, статус и дату релиза.
- [ ] Текущая цена и история разделены по площадке и виду предложения (`key`, `gift`, `account`, `rent`, `other`).
- [ ] Несколько пользователей одной игры используют один набор объективных ценовых данных.
- [ ] Клиент не может записывать или подменять серверную текущую цену.
- [ ] Пригодные данные из `favorites` и `price_snapshots` переносятся без потери пользовательского избранного и без дубликатов.
- [ ] Миграции проверены на чистой PostgreSQL и на базе с существующими данными.

## Technical Notes

Схема должна отделять каталог игр и ценовые наблюдения от пользовательских предпочтений. Старые миграции не переписываются; создаются новые обратимые миграции и явная процедура backfill.
