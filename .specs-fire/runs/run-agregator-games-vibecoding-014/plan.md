# Implementation Plan: Перекомпоновка карточки цен для Telegram

## Approach

Перестроить PNG-карточку в две горизонтальные зоны: верхняя сохраняет всю обложку и использует только мягкий градиент, зерно и контур; нижняя — единая тёмная панель с названием и ценовыми источниками. Крупным кеглем рисуется минимальная цена каждой площадки, а типы предложений и число лотов остаются вторичным текстом. Цвета ограничиваются тёмной базой, коралловым акцентом и голубым/фиолетовым служебными оттенками.
