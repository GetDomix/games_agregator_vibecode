# План: главное меню и навигация бота без команд

## Цель

Пользователь обычным способом управляет ботом кнопками: начинает поиск, открывает избранное или алерты, получает справку и возвращается в меню. Команды остаются только запасным входом.

## Подход

1. Добавить постоянное reply-меню с четырьмя действиями: «Найти игру», «Избранное», «Алерты», «Помощь».
2. После `/start` и завершения привязки показывать это меню вместо списка команд.
3. Направить на те же существующие обработчики: поиск запросит название, остальные откроют текущие разделы без новой бизнес-логики.
4. Добавить inline-кнопку возврата в главное меню там, где это не ломает текущий сценарий настройки алерта; не очищать FSM при простой навигации.
5. Покрыть меню изолированными handler/UI-тестами и прогнать тесты бота в Docker.

## Границы

- Не меняем API, цены, избранное, алерты или дизайн ценовой карточки.
- Не удаляем slash-команды: они остаются технической альтернативой.

## Файлы

- `bot/ui.py` — клавиатуры и подписи меню.
- `bot/main.py` — обработчики reply/inline-действий и регистрация.
- `bot/tests/test_ui.py`, `bot/tests/test_handlers.py` — изолированные сценарии.

## Проверка

- `/start` показывает меню.
- Каждая кнопка вызывает соответствующий текущий сценарий.
- Ввод названия после «Найти игру» по-прежнему ищет игру.
- Прогон: `python -m unittest discover -s tests -v` в контейнере `radar-bot`.
