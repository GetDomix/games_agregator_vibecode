# Implementation Plan: Полная ценовая карточка игры в Telegram

## Approach

1. Перестроить PNG-карточку: оставить крупную обложку слева, но вписывать её целиком через contain-компоновку с нейтральным фоном, а не обрезать через cover.
2. Перенести внутрь изображения основную информацию: Steam, а также отдельные строки каждого доступного вида предложения Plati.Market и GGsel. Для каждой строки показывать понятный тип, минимальную цену и счётчик предложений; для пустого или обновляющегося источника — честный статус.
3. Сохранить стилистику сайта: тёмная панель, акцентные цвета источников, ясная визуальная иерархия. Декоративные игровые ассеты в этот срез не добавлять: они относятся к отдельному visual-system work item.
4. Отправлять карточку одним photo-сообщением с коротким caption и action-клавиатурой, без второго текстового сообщения, повторяющего цены. Стратегию редактирования существующих сообщений не менять: она является следующим отдельным work item.
5. Расширить изолированные тесты renderer и handlers: полная обложка, несколько offer kinds, отсутствие цен, состояние фонового обновления и один вызов отправки карточки.

## Technical Details

Laravel API уже отдаёт `by_kind` для Plati и GGsel в `/api/internal/telegram/games/{appid}`; расширять backend-контракт не требуется. Бот продолжит читать только серверное хранилище, поэтому новая карточка не добавит внешних запросов к магазинам.

Обложка будет вписываться целиком, а свободные поля оформляться фоном и затемнением. Это исключает обрезание, но у очень широких или высоких исходников могут появляться аккуратные поля — это осознанный компромисс ради сохранения изображения целиком.
