# Implementation Walkthrough: Полная ценовая карточка игры в Telegram

## Summary

Telegram-карточка теперь показывает целую обложку игры и отдельные цены Steam, Plati.Market и GGsel по доступным видам предложений. Карточка отправляется одним photo-сообщением с короткой подписью и действиями, поэтому список цен не дублируется под изображением.

## Structure Overview

Laravel по-прежнему формирует общий payload из серверного хранилища цен. Бот получает его через существующий internal API, renderer преобразует его в PNG, а handler отправляет PNG, короткий caption и inline-клавиатуру одним сообщением. Внешние магазины и Telegram Bot API не вызывались в тестах.

## Key Implementation Details

### 1. Обложка целиком

Renderer использует contain-компоновку, поэтому исходная обложка не crop-ится. Свободное пространство заполняется размытым вариантом той же картинки и затемнением в цветовой системе сайта.

### 2. Цены внутри карточки

Steam показан отдельной строкой, а Plati.Market и GGsel — отдельными карточками для каждого доступного key/gift/account/rent. Пустой, недоступный, анонсированный или обновляющийся источник получает статус вместо выдуманной цены.

### 3. Одно пользовательское сообщение

Handler объединяет изображение, caption и inline-клавиатуру в `answer_photo`. Полная стратегия редактирования уже существующих сообщений намеренно не включена: это следующий work item `telegram-message-continuity`.

## Decisions Made

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Отображение обложки | contain + стилизованный фон | Полнота изображения важнее отсутствия полей. |
| Цены marketplace | отдельная карточка на вид предложения | Нельзя смешивать ключ, гифт, аккаунт и аренду в одну цену. |
| Текст под PNG | короткий caption без списка цен | Исключает визуальную кашу и повторение данных. |
| Backend-контракт | не менялся | `by_kind` уже приходит из общего серверного хранилища. |
