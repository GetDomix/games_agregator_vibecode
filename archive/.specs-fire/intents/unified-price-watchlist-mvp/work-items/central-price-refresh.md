# Work Item: Централизованное обновление цен

## Description

Заменить пользовательские и per-favorite запросы единым серверным конвейером, который обновляет уникальные игры по расписанию с контролем нагрузки и состояния источников.

## Acceptance Criteria

- [ ] В одном цикле каждая уникальная отслеживаемая игра обновляется не более одного раза на источник.
- [ ] Выпущенные игры планируются не реже одного раза в 3 часа.
- [ ] Игры `coming_soon` проверяются только через Steam и не чаще одного раза в сутки; Plati и GGsel для них не вызываются.
- [ ] После обнаружения релиза игра автоматически переходит на трёхчасовой цикл выбранных источников.
- [ ] Новая неизвестная игра ставится на фоновое первичное заполнение, не блокируя пользовательский HTTP-запрос.
- [ ] Есть защита от перекрывающихся запусков, повторные попытки с backoff, задержки и отдельный бюджет каждого источника.
- [ ] Ошибки источника не удаляют последнюю успешную цену; API видит время свежести и состояние ошибки.

## Technical Notes

Laravel является владельцем расписания и очереди. Python-бот не должен запускать общий сканер. Источники вызываются через существующие сервисы с адаптерами, пригодными для подмены в тестах.
