# Work Item: Поиск из серверного хранилища

## Description

Сохранить существующий пользовательский поиск и карточки, но выдавать цены из канонического хранилища и запускать обновление неизвестных игр асинхронно.

## Acceptance Criteria

- [ ] Существующий контракт карточек адаптирован без синхронного обращения ко всем магазинам при каждом действии пользователя.
- [ ] Актуальные и устаревшие данные явно различаются временем последнего успешного обновления.
- [ ] Для неизвестной игры API возвращает состояние фонового обновления вместо ожидания всех поставщиков.
- [ ] Для `coming_soon` возвращается карточка Steam без предложений Plati и GGsel.
- [ ] Предложения фильтруются по виду и ранжируются только по объективным данным цены и продаж.
- [ ] Поиск доступен бесплатно, но защищён техническим rate limit.

## Technical Notes

Поиск локального каталога является основным путём. Discovery неизвестного `appid` допускает один контролируемый запрос и создаёт фоновое задание; ценовые ответы всегда читаются из PostgreSQL.
