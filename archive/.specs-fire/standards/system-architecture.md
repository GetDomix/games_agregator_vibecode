# Архитектура системы

```text
Пользователь
  -> Caddy
     -> React frontend
     -> Laravel API
        -> PostgreSQL
        -> внешние источники цен

Telegram Radar Bot
  -> Laravel API (защищённый сервисный вызов)
  -> Telegram
```

## Границы модулей

- `frontend/` отвечает за интерфейс и вызовы HTTP API.
- `backend/` содержит бизнес-логику, API, доступ к данным, фоновые задачи и интеграции источников цен.
- `bot/` реализует Telegram-радар и обращается к backend по внутреннему API.
- `deploy/` и `docker-compose.yml` определяют локальную и серверную инфраструктуру.

## Связи и риски

- Контракт Laravel API является границей совместимости для фронтенда и бота.
- PostgreSQL обслуживается backend; доступ к данным минуя Laravel не предполагается.
- Настройки URL, токенов и учётных данных задаются через окружение.
