# Стандарты кода

## Общие

- Следовать существующему стилю и локальной структуре каждого модуля.
- Избегать несвязанных рефакторингов и изменений форматирования.
- Новые конфигурационные значения добавлять в `.env.example`, если они необходимы для работы локально; реальные значения не коммитить.

## Frontend

- Использовать TypeScript и React-компоненты в существующем стиле проекта.
- Не обходить проверку типов; перед передачей результата выполнять `npm run build` для затронутой фронтенд-логики.
- Следовать правилам `frontend/.oxlintrc.json`.

## Backend

- Соблюдать Laravel conventions: контроллеры, модели, Form Request/валидация и миграции размещать в соответствующих каталогах.
- Любые входные данные валидировать на границе API.
- Не раскрывать токены и внутренние ошибки в API-ответах.

## Bot

- Конфигурацию получать из окружения через существующий модуль конфигурации.
- Сетевые запросы должны иметь явные таймауты и обрабатываемые ошибки.
