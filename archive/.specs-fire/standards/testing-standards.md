# Стандарты тестирования

## Backend

- Для логики API и моделей добавлять или обновлять Laravel-тесты.
- Выполнять `php artisan test` в `backend/`.
- Изменения миграций проверять на чистой тестовой PostgreSQL базе.

## Frontend

- Выполнять `npm run lint` и `npm run build` в `frontend/`.
- Для пользовательских сценариев вручную проверять затронутый экран или маршрут.

## Bot

- Для изменённой прикладной логики добавлять изолированные тесты, когда в репозитории есть подходящий тестовый контур.
- Не обращаться к реальному Telegram API во время тестов.

## Интеграция

- Если меняется контракт API, проверять связанный фронтенд или бот.
- Не запускать деплой как часть обычной проверки функции.
