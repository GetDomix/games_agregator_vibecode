# Конституция проекта

## Область действия

«Игроскан» состоит из React-фронтенда, Laravel API, Telegram-бота и Docker Compose-инфраструктуры. Изменения должны быть ограничены нужным модулем и не должны без необходимости затрагивать другие части проекта.

## Обязательные правила

- Не добавлять секреты, токены, ключи или файлы `.env` в Git.
- Перед изменением API учитывать его потребителей: фронтенд, бот и внешние интеграции.
- Для изменений схемы данных использовать Laravel migrations; не менять структуру PostgreSQL вручную.
- Сохранять обратную совместимость публичных API, если миграция клиентов не входит в согласованный объём работы.
- Не менять конфигурацию развёртывания, Caddy или Docker Compose без явной необходимости и проверки.
- Проверять затронутый модуль его штатными командами перед завершением работы.

## Git и проверка

- Не включать в коммит чужие или сгенерированные изменения.
- Перед реализацией проверять `git status` и сохранять существующие незавершённые изменения пользователя.
- Критичные изменения (аутентификация, платежи, секреты, миграции, публичный API, деплой) выполняются в режиме `validate`.
